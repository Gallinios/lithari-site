# Λιθάρι – Μεζεδοπωλείο

Site για φανταστικό μεζεδοπωλείο στο Ναύπλιο.

> Φανταστική επιχείρηση. Όλα τα ονόματα, οι τιμές και τα στοιχεία επικοινωνίας είναι επινοημένα για τις ανάγκες του σχεδιασμού.

## Χαρακτηριστικά

- Μενού σε καρτέλες (Ορεκτικά, Θάλασσα, Κυρίως, Γλυκά, Ποτά) που φτιάχνεται από JavaScript
- Ωράριο που τονίζει αυτόματα τη σημερινή μέρα
- Φόρμα κράτησης με έλεγχο πεδίων και απόρριψη ημέρας που είναι κλειστά
- Εικονογράφηση σε SVG (ασβεστωμένος τοίχος, παντζούρια, ελιά)
- Light / dark mode, responsive

## Τεχνολογίες

HTML, CSS και JavaScript χωρίς frameworks, σε ένα αρχείο. Γραμματοσειρές από Google Fonts.

## Εκτέλεση

Άνοιξε το `index.html` σε οποιονδήποτε browser.
